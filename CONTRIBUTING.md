# Contributing

This started as a personal tool, so there's no formal process — just open an issue or a PR.

A few things that make review faster:
- Keep PRs scoped to one change; small diffs get looked at sooner than big ones.
- If you're adding a feature that changes the data model, update `supabase/schema.sql` in the same PR.
- No test suite yet — `npm run build` passing is the current bar.
